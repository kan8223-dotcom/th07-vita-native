### pthread-embedded (LGPL)

The VPK statically links VitaSDK's pthread-embedded, which is licensed as a whole
under the GNU LGPL v2 or later. Its corresponding source is
<https://github.com/vitasdk/pthread-embedded> at commit
`11d2e5722d98c86f33c908fc47b2cf6e55205db5`, and a copy is attached to each release.
The complete source and build files of this port are in this repository, so you can
rebuild pthread-embedded (or a modified version), install it into your VitaSDK, and
relink the program with the build commands in README.md.

not part of this repository or the VPK.
